UX Guidelines for Floating Settings Panel

The floating settings panel consists of three tabs, each with a clearly defined purpose.

Global Behavior Rules:

Tab order
Content → Design → Block Settings
Tab visibility
Keep all three tabs visible
Default tab
Open Content when a block is first selected
Settings availability
Only display controls supported by the selected block
Preview
Reflect changes immediately when supported
Panel Size
Fixed height of 500px
Accessibility
Keep visible focus, tooltips for icon-only tabs, and clear active states

Content Tab

Block Label

This tab contains settings related to the block's content, data, and information.

Examples: Titles, descriptions, images, content sources, Add and manage items, number of items displayed, filters, and sorting.

Rules: Content-specific controls belong here. Settings should update the preview when changed. The available fields vary by block type.

Blocks

This tab contains visual customization options, including design, layout, and background settings.

Example: Layout styles, grid columns, spacing, alignment, colors, typography, corner radius, background images, and overlays.

Rules: Group controls into labeled sections such as Layout, Appearance, and Background. Only display settings supported by the selected block.

Controls the block's structural properties and behavior, including dimensions, padding, layer positioning, and animations.

Rule: This tab always occupies the third position. Use consistent labels and ordering across all blocks.

Device settings adjust how this block behaves on mobile breakpoints.

Examples: Show or hide the block on mobile, and mobile-only layout overrides when the block supports them.

Rules: Icon-only tabs need a tooltip and accessible name. Keep focus visible and the active state clear.

Nested Layer

Nested layers open as a full takeover of the floating panel.

Examples: Text styles, advanced filters, element lists, and other content-specific drill-ins.

Rules: Use a back control and clear title. Hide the main tabs while the nested layer is open. Return focus to the row that opened it.
